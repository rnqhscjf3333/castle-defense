# 성 지키기

사방에서 몰려오는 적으로부터 중앙 성을 지키는 실시간 디펜스 게임. 유닛(검사·궁수·사제)을 뽑고, 라운드마다 업그레이드를 골라 **50라운드**를 버틴다. 1막(1~30라운드, 30라운드 보스 암흑 기사단장)을 넘기면 연출과 함께 **2막**이 열리고(길 2개 추가·맵이 어두워짐·적이 훨씬 빠르게 강해짐), 50라운드의 **마왕**을 쓰러뜨리면 승리한다.

**플레이**: https://rnqhscjf3333.github.io/castle-defense/

현재 단계: **3단계** — 맵·카메라·성·유닛·적·자동 라운드 + 업그레이드 카드 + 전직 + 2막 + 캐릭터/배경 그래픽 + 밸런스 보정

## 실행
빌드 도구 없이 동작한다. `index.html`을 브라우저로 열면 된다 (또는 `python3 -m http.server` 후 접속).

## 조작
- 화면 이동: 빈 곳 드래그 / 확대·축소: 휠·핀치 / 미니맵 클릭으로 이동 / `H` 성으로
- **시작 골드 210**: 검사·궁수·사제를 한 명씩(어떤 순서로든) 바로 뽑을 수 있다. 이후는 적을 처치해 골드를 모아 뽑고, **하나 뽑을 때마다 모든 유닛의 가격이 오른다** (인구 제한 없음). 카드로 얻는 **특수 유닛(골렘·용사·포탑)은 가격을 올리지 않는다.** 가격이 오르면 카드에 `+N`이 뜬다
- 유닛은 성 광장 둘레에 **사방으로 고르게**(검사 바깥·궁수 중간·사제 안쪽 고리, 황금각 배치 + 살짝 흔들림) 서 있다가 스스로 싸우고 끝나면 제자리로 돌아온다. 적이 성 가까이(420px) 오면 그쪽으로 서서히 모인다. 별도 명령/모드는 없다.
- 적은 맵 끝이 아니라 **성에서 700px 떨어진 길 위의 붉은 포탈**에서 나타나 몇 초 안에 도착한다 (출현 순간 붉은 고리 효과)
- 라운드는 시작부터 40초마다 자동으로 넘어간다 (적이 남아 있어도 다음 라운드가 시작됨)
- 업그레이드/전직 선택창: `1` `2` `3` 선택, `R` 다시 뽑기(카드만) (고르는 동안 시간 정지) / `U` 강화 목록(전직 이력 포함)

## 적과 보스
**일반 적** (라운드가 갈수록 종류가 늘어난다): 돌격병(1R~) · 방패병(3R~) · **사수**(4R~, 멀리서 포물선 화살) · **폭파병**(7R~, 닿으면 자폭해 범위 피해) · **주술사**(10R~, 뒤에서 다친 적을 치유) · **거한**(13R~, 느리고 단단함). 체력·수·속도도 라운드마다 오른다 (20R부터 대혼란).

**보스** (5라운드마다, **라운드 시작과 함께 반드시 등장**) — 1막 5·10·15·20·25라운드에는 아래 일반 보스 5종이 **게임마다 무작위 순서로 한 번씩**, 2막 35·40·45라운드에는 다시 섞어서 3종이 나온다. 30라운드는 **암흑 기사단장**, 50라운드는 **마왕**으로 고정. 체력은 라운드별 표(누가 나오든 같은 라운드면 같은 체력)이고, 패턴 강도는 나오는 라운드에 맞춰 조정된다. 보스는 전 라운드에 "다음 라운드 보스: 이름"으로 미리 알려 준다.
| 보스 | 패턴 |
|---|---|
| 돌격왕 | 주기적으로 성을 향해 돌진 |
| 소환사 | 졸개(돌격병)를 계속 불러냄 |
| 포격대장 | 아군 밀집 지점에 범위 포격 (착탄 지점을 미리 표시) + 사수 소환 |
| 철벽 장군 | 방어막(받는 피해 감소) + 돌진 + 방패병 소환 |
| 광전사 | 체력 50% 이하에서 분노(더 빠르고 강함) + 돌진 + 포격 |
| 암흑 기사단장 (30R) | 폭파병 소환 + 쌍포격 + 방어막 + 분노. **처치할 때까지 31라운드로 넘어가지 않는다** |
| 마왕 (50R) | 폭파병 소환 + 3연 포격 + 방어막 + 분노 + 돌진 (최종 보스) |

**2막** (30라운드 보스 처치 후): 짧은 연출(건너뛰기 가능) → 길이 6갈래에서 **8갈래**로 늘고, 맵이 **어둡고 푸르스름**해지며(성 주변만 횃불로 밝음), 적의 수·체력·속도가 훨씬 가파르게 오른다. 1막 클리어 보상으로 전직도 한 번 더 고른다.

**보스 표시**: 보스 전 라운드에 "다음 라운드 보스" 예고, 보스 라운드는 라운드 문구와 큰 경고 배너로 표시, 화면 위 가운데에 **큰 보스 체력 바**(이름·체력 숫자·현재 상태·가진 패턴), 보스가 화면 밖이거나 **UI(보스 바·HUD·미니맵·버튼·하단 유닛 카드)에 가려진 위치**에 있으면 UI를 피한 안전 영역 가장자리에 **화살표**(이름·거리)가 나오고, 미니맵 고리로도 위치를 알려준다.

**투사체**는 포물선으로 날아가며, 몸 중심이 아니라 **포구·활 위치**(성 대포 끝, 궁수의 활, 포탑 포신, 보스 어깨 대포/머리 위)에서 출발한다 (아군 화살·성 포탄, 적 화살, 보스 포탄).

## 전직 (보스 처치 보상)
보스를 처치하면 시간이 멈추고 **전직 선택**이 뜬다(최대 3개 제시, 1·2·3 키). 검사·궁수·사제 중 하나를 골라 승급시키며, 이미 전직한 직업은 같은 갈래의 2단계로 한 번 더 강해진다. 효과는 이미 뽑은 유닛과 앞으로 뽑을 유닛 모두에 적용되고, 겉모습(별·소품)도 바뀐다. (50라운드 마왕은 승리로 끝나므로 전직 없음. 30라운드 보스를 처치하면 2막 연출과 함께 전직 선택도 뜬다)
| 직업 | 1단계 (갈래 선택) | 2단계 |
|---|---|---|
| 검사 | **기사** 체력 +80%·받는 피해 -20% / **투사** 공격력 +50%·공속 +20% | 성기사(체력+·피해감소+·초당 2% 회복) / 검성(공격력+·주변 베기 50%) |
| 궁수 | **저격수** 공격력 +60%·사거리 +60·공속 -15% / **속사수** 공속 +50%·이속 +15% | 명사수(공격력+·관통) / 폭풍사수(공속+·3번째 공격마다 2발) |
| 사제 | **성직자** 치유량 +60%·범위 +60 / **주교** 치유량 +20%·라운드당 부활 1회 | 대성직자(치유량+·치유 속도+) / 대주교(치유량+·부활 +1) |

## 업그레이드 카드 (라운드를 넘길 때마다 3택 1)
- **희귀도**: 일반 70% · 희귀 25% · 영웅 5%. 보스 클리어 직후(라운드 6, 11, …)에는 희귀 이상 1장 이상 보장 + 다시 뽑기 +1 (기본 2회)
- **유닛 강화**: 체력/공격력/공속(대상 유닛은 카드에 표시, 사제는 효과 2배) + 특성(검사 방어 자세·돌진, 궁수 관통 화살·연사, 사제 광역 치유·부활)
- **성 강화**: 포격(공격력·공속·사거리·폭발탄·연쇄 번개·대형 포탄) / 보급 오라(치유·군기·철벽·신속·오라 강화) / 요새(체력·자동 수리·가시 방벽)
- **특수 소환** (가격을 올리지 않음, 전부 **계열의 강화·전직을 받음**): 골렘·용사 = 검사 계열 / 자동 포탑 = 성 계열(성 공격력·공속·사거리) / **명궁**(사거리 300 영웅 궁수, 화살 1명 관통)·**연노병**(2명씩, 초당 3발 이상)·**발리스타**(설치형, 큰 화살이 적 2명 관통) = 궁수 계열
- 같은 카드는 종류별 중복 상한이 있고, 상한에 닿으면 풀에서 빠진다.

## 구조
- `core.js` — 게임 규칙 전부 (DOM 없음, 시드 난수 + 고정 시간 단계 → 결정론적). Node에서도 실행됨. 수치는 위쪽 `CFG`(`balance`, `cardVals`, `popExpand` …)와 `CARD_DEFS`.
- `main.js` — 렌더링, 입력, UI
- `scenery.js` — 맵 배경(풀밭·흙길 6갈래·돌바닥 광장·숲·바위·덤불·꽃)과 성(탑 4개·본성·대포·깃발·정문, 체력이 줄면 금→연기→불) 그리기. 배경은 512px 조각으로 한 번만 그려 캐시하고, 나무는 유닛과 y 순서로 함께 그린다. 규칙과 무관한 렌더링 전용 코드
- `figures.js` — 캐릭터 그리기 (동그란 머리 + 네모 몸통 + 칼·방패·활·지팡이·도끼, 적 6종·보스 6종). 규칙과 무관한 렌더링 전용 코드
- `tools/balance.mjs` — 밸런스 시뮬레이터 (아래)
- 테스트
  - `node tests/smoke.js` — 로직(골드·가격 규칙, 자동 라운드, 카드 규칙, 결정론, 봇 플레이)
  - `node tests/e2e.mjs` — 실제 Chrome을 실시간으로 조작 (게임 루프, 카드창, 드래그/휠, 종료/재시작). Chrome 경로는 `CHROME`, 대상 주소는 `URL0` 환경변수로 변경 가능
  - `tests/ui-test.html` — 입력 이벤트 빠른 점검 (`--allow-file-access-from-files --virtual-time-budget=8000 --dump-dom`)

## 밸런스 시뮬레이터
같은 `core.js`를 봇이 수천 판 돌려서 수치를 맞춘다 (멀티코어, 120판에 약 7초).
```
node tools/balance.mjs baseline 80                 # 정책별 클리어율·도달 라운드
node tools/balance.mjs hist 100                    # 종료 라운드 분포 (어디서 막히는지)
node tools/balance.mjs coredmg 80                  # 성이 어떤 공격에 얼마나 맞는지
node tools/balance.mjs jobs 60                     # 전직별 기여도
node tools/balance.mjs cards 60 [smart] [save]     # 카드별 기여도 (그 카드를 보이면 항상 고를 때의 평균 라운드 변화)
node tools/balance.mjs sweep hpSlope 0.07,0.055 60  # 수치 스윕 (balance.*, popCap, startGold, leash, bias)
```
**밸런스 상태** (봇 120판. 기준 정책 = 검사 3:궁수 2:사제 1 구성 + 측정값과 설계 우선순위를 섞은 카드 가중치 + 카드 다시 뽑기 사용. "모든 업그레이드와 유닛을 적절히 쓰는 플레이어"의 대용)
| 정책 | 30라운드 보스 처치(1막 클리어) | 50라운드 클리어 | 평균 라운드 |
|---|---|---|---|
| 숙련 카드 선택 | 약 76% | 약 28% | 40.6 |
| 무작위 카드 선택 | 약 46% | 약 12% | 32.8 |

설계 목표: 적절히 플레이하면 **1막 약 75%, 50라운드 약 25%**. 일반 라운드(잡몹 구간)는 이전보다 훨씬 어렵다(체력 증가율 0.055→0.125): 숙련도 22라운드 전에 약 4%, 무작위는 약 18%가 죽는다. 2막은 체력 증가 기울기 0.35(1막 후반 0.14), 적 수 +3/라운드, 이동 속도 ×1.08로 가파르게 오른다.

**이번 보정에서 찾은 것**: ① 라운드가 40초마다 자동으로 넘어가서 30라운드 보스가 살아 있어도 31라운드가 시작되는 결함 → **30라운드는 보스를 처치해야 넘어간다**(2막 전환의 조건) ② **광전사**가 몇 라운드에 나오든 벽이었음(25R 13/20, 35R 8/9, 40R 10/10, 45R 15/17명 사망) → 원인은 포격 피해·발수(2막에서 발수가 +1 되는 규칙까지 겹침). 광전사 포격을 피해 55·1발로 낮춰 보스별 사망이 고르게 분포 ③ 50라운드 동안 성 체력이 회복되지 않아 누적 소모로 쓰러짐 → 라운드마다 최대 체력의 4% 기본 수리 ④ 유닛 구성은 검사 3 이상이면 비슷(33~34.5라운드), 사제 비중이 높을수록 소폭 유리 ⑤ 카드별 기여도는 50라운드 게임의 분산이 커서 대부분 오차(±2) 안.

```
node tools/balance.mjs hist 120        # 정책별 30R 보스 처치·50R 클리어율, 종료 라운드 분포
node tools/balance.mjs where 120       # 죽은 구간별로 그 구간 보스가 누구였는지
node tools/balance.mjs policy '{"ratio":{"sword":3,"archer":2,"priest":1}}' 60   # 정책 덮어쓰기
node tools/balance.mjs sweep bossPool.4.abil.artillery.dmg 90,60 60               # 점 표기로 어떤 수치든 스윕
```

**지금까지 찾아 고친 것**: ① 유닛이 성에서 너무 멀리 추격해 각개격파됨 → 추격 한계 520→240 ② 효과 없는 이속 카드 제거, 약한 카드(방어·소환·사제) 상향, 강한 카드(관통 화살·대형 포탄) 소폭 하향 ③ 명령 모드 제거 후 새 배치 방식(`ai.bias`, `leash`) 조정.

**알려진 한계**: 봇 기준 수치라서 사람의 실제 클리어율은 다를 수 있다. 카드 간 기여도 차이가 작아 카드 선택의 영향이 크지 않다. 2막의 일반 보스(35·40·45라운드)는 1막 보스를 같은 패턴으로 강화한 것이라 구성이 비슷하다.

- `config.js`의 `API_URL`이 비어 있으면 이 브라우저의 개인 랭킹만 동작한다.
- 서버는 `server/apps-script.gs`(구글 앱스 스크립트 + 구글 시트, 무료). 파일 맨 위의 설치 방법(5분)을 따라 배포한 뒤 웹 앱 주소를 `API_URL`에 넣는다.
- 랭킹 점수: `(도달 라운드 + 클리어면 1) × 100000 + (클리어면 빠를수록, 실패면 처치 수)`.
- 게임이 끝나거나 도중에 나가면 플레이 기록(점수, 강화·전직 선택, 유닛 구성, 성이 맞은 원인, 라운드별 상태, 렉 횟수, 기기 환경)이 `logs` 탭에 쌓인다. 닉네임 외 개인정보는 보내지 않고, 기기별 익명 ID만 쓴다. 전송 실패 시 브라우저에 보관했다가 다시 보낸다.
- 점수는 브라우저가 보내는 값이라 조작할 수 있다. 서버에서는 범위·시간만 검사한다.

## 가격 방식 변경 · 50R 부활 제거 · 만렙 인구 제한 해제
- 유닛 가격 = 기본가 × 1.02^(전체 인구) × 1.04^(같은 종류 인구). 한 종류만 계속 뽑으면 예전(6%씩)과 비슷하고, 섞어 뽑으면 덜 오른다. 병력을 잃으면 가격도 내려가 복구가 쉽다.

- 성 최대 레벨(8)이 되면 인구 제한이 없다.

- 왼쪽 강화 목록 삭제(정보 창 "강화 정보"로 통합), 배속 버튼은 왼쪽 위, 설정은 ⚙️. 소리는 설정 창의 배경음악/효과음 슬라이더(소리 켬 버튼 삭제, M 키는 음소거 토글).
- 강화 정보 > 유닛/특수 유닛 탭에 유닛 외형 표시.
- 오른쪽 킬로그: 아군이 죽으면 [죽인 적 얼굴 ⚔️ 쓰러진 아군 얼굴], 사제 부활은 초록색 [사제 ✚ 부활한 아군]. 최대 5줄, 새 줄이 위로 들어오고 오래된 줄은 흐려지며 사라진다. (적의 죽음은 너무 많아 표시하지 않음)
- 수비 모드: 근접은 자기 자리 58px 이내로 들어온 적을 상대하러 나간다 (`CFG.holdRadius`).
- 피해 감소 문구를 "피해를 N% 방어" 형태로 통일.
- 개발자 모드(메인 메뉴 > 개발자): 라운드 2~100 선택 → `C.devSetup(S, r)`이 성 레벨·강화 카드(`tools/weights.json` 가중치)·전직·보스 보상·유닛 수를 그 라운드에 맞게 구성, 골드 무한(∞ 표시). `S.dev`면 `checkRun`이 비정상 처리 → 랭킹 등록·로그 전송·통계/도감/업적 기록 모두 제외. `?dev=N` 파라미터로도 시작 가능.
