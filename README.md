# 성채방어

사방에서 몰려오는 적으로부터 중앙 성채를 지키는 실시간 디펜스 게임. 유닛(검사·궁수·사제)을 뽑아 지휘하고, 라운드마다 업그레이드를 골라 30라운드를 버틴다.

**플레이**: https://rnqhscjf3333.github.io/castle-defense/

현재 단계: **3단계** — 맵·카메라·성채·유닛·적·자동 라운드 + 업그레이드 카드 + 캐릭터 그래픽 (밸런스 재보정 예정)

## 실행
빌드 도구 없이 동작한다. `index.html`을 브라우저로 열면 된다 (또는 `python3 -m http.server` 후 접속).

## 조작
- 화면 이동: 빈 곳 드래그 / 확대·축소: 휠·핀치 / 미니맵 클릭으로 이동 / `H` 성채로
- **시작 골드 210**: 검사·궁수·사제를 한 명씩(어떤 순서로든) 바로 뽑을 수 있다. 이후는 적을 처치해 골드를 모아 뽑고, **하나 뽑을 때마다 모든 유닛의 가격이 오른다** (인구 제한 없음). 카드로 얻는 **특수 유닛(골렘·용사·포탑)은 가격을 올리지 않는다.** 가격이 오르면 카드에 `+N`이 뜬다
- 유닛은 성채 광장 둘레에 **사방으로 고르게**(검사 바깥·궁수 중간·사제 안쪽 고리, 황금각 배치 + 살짝 흔들림) 서 있다가 스스로 싸우고 끝나면 제자리로 돌아온다. 적이 성채 가까이(420px) 오면 그쪽으로 서서히 모인다. 별도 명령/모드는 없다.
- 적은 맵 끝이 아니라 **성채에서 700px 떨어진 길 위의 붉은 포탈**에서 나타나 몇 초 안에 도착한다 (출현 순간 붉은 고리 효과)
- 라운드는 시작부터 40초마다 자동으로 넘어간다 (적이 남아 있어도 다음 라운드가 시작됨)
- 업그레이드/전직 선택창: `1` `2` `3` 선택, `R` 다시 뽑기(카드만) (고르는 동안 시간 정지) / `U` 강화 목록(전직 이력 포함)

## 적과 보스
**일반 적** (라운드가 갈수록 종류가 늘어난다): 돌격병(1R~) · 방패병(3R~) · **사수**(4R~, 멀리서 포물선 화살) · **폭파병**(7R~, 닿으면 자폭해 범위 피해) · **주술사**(10R~, 뒤에서 다친 적을 치유) · **거한**(13R~, 느리고 단단함). 체력·수·속도도 라운드마다 오른다 (20R부터 대혼란).

**보스** (5라운드마다, **라운드 시작과 함께 반드시 등장**) — 5·10·15·20·25라운드에는 아래 일반 보스 5종이 **게임마다 무작위 순서로 한 번씩** 나오고, 30라운드는 **마왕 고정**이다. 체력은 라운드별 표(누가 나오든 같은 라운드면 같은 체력)이고, 패턴 강도(포격 피해·발수, 소환 수, 돌진 속도, 방어막 효율)는 나오는 라운드에 맞춰 조정된다. 보스가 누구인지는 전 라운드에 "다음 라운드 보스: 이름"으로 미리 알려 준다.
| 보스 | 패턴 |
|---|---|
| 돌격왕 | 주기적으로 성채를 향해 돌진 |
| 소환사 | 졸개(돌격병)를 계속 불러냄 |
| 포격대장 | 아군 밀집 지점에 범위 포격 (착탄 지점을 미리 표시) + 사수 소환 |
| 철벽 장군 | 방어막(받는 피해 감소) + 돌진 + 방패병 소환 |
| 광전사 | 체력 50% 이하에서 분노(더 빠르고 강함) + 돌진 + 포격 |
| 마왕 (30라운드 고정) | 폭파병 소환 + 쌍포격 + 방어막 + 분노 |

**보스 표시**: 보스 전 라운드에 "다음 라운드 보스" 예고, 보스 라운드는 라운드 문구와 큰 경고 배너로 표시, 화면 위 가운데에 **큰 보스 체력 바**(이름·체력 숫자·현재 상태·가진 패턴), 보스가 화면 밖이거나 **UI(보스 바·HUD·미니맵·버튼·하단 유닛 카드)에 가려진 위치**에 있으면 UI를 피한 안전 영역 가장자리에 **화살표**(이름·거리)가 나오고, 미니맵 고리로도 위치를 알려준다.

**투사체**는 포물선으로 날아가며, 몸 중심이 아니라 **포구·활 위치**(성채 대포 끝, 궁수의 활, 포탑 포신, 보스 어깨 대포/머리 위)에서 출발한다 (아군 화살·성채 포탄, 적 화살, 보스 포탄).

## 전직 (보스 처치 보상)
보스를 처치하면 시간이 멈추고 **전직 선택**이 뜬다(최대 3개 제시, 1·2·3 키). 검사·궁수·사제 중 하나를 골라 승급시키며, 이미 전직한 직업은 같은 갈래의 2단계로 한 번 더 강해진다. 효과는 이미 뽑은 유닛과 앞으로 뽑을 유닛 모두에 적용되고, 겉모습(별·소품)도 바뀐다. (30라운드 최종 보스는 승리로 끝나므로 전직 없음)
| 직업 | 1단계 (갈래 선택) | 2단계 |
|---|---|---|
| 검사 | **기사** 체력 +80%·받는 피해 -20% / **투사** 공격력 +50%·공속 +20% | 성기사(체력+·피해감소+·초당 2% 회복) / 검성(공격력+·주변 베기 50%) |
| 궁수 | **저격수** 공격력 +60%·사거리 +60·공속 -15% / **속사수** 공속 +50%·이속 +15% | 명사수(공격력+·관통) / 폭풍사수(공속+·3번째 공격마다 2발) |
| 사제 | **성직자** 치유량 +60%·범위 +60 / **주교** 치유량 +20%·라운드당 부활 1회 | 대성직자(치유량+·치유 속도+) / 대주교(치유량+·부활 +1) |

## 업그레이드 카드 (라운드를 넘길 때마다 3택 1)
- **희귀도**: 일반 70% · 희귀 25% · 영웅 5%. 보스 클리어 직후(라운드 6, 11, …)에는 희귀 이상 1장 이상 보장 + 다시 뽑기 +1 (기본 2회)
- **유닛 강화**: 체력/공격력/공속(대상 유닛은 카드에 표시, 사제는 효과 2배) + 특성(검사 방어 자세·돌진, 궁수 관통 화살·연사, 사제 광역 치유·부활)
- **성채 강화**: 포격(공격력·공속·사거리·폭발탄·연쇄 번개·대형 포탄) / 보급 오라(치유·군기·철벽·신속·오라 강화) / 요새(체력·자동 수리·가시 방벽)
- **특수 소환**: 자동 포탑(최대 3), 골렘, 용사 (일시적으로 소환되는 카드는 없음)
- 같은 카드는 종류별 중복 상한이 있고, 상한에 닿으면 풀에서 빠진다.

## 구조
- `core.js` — 게임 규칙 전부 (DOM 없음, 시드 난수 + 고정 시간 단계 → 결정론적). Node에서도 실행됨. 수치는 위쪽 `CFG`(`balance`, `cardVals`, `popExpand` …)와 `CARD_DEFS`.
- `main.js` — 렌더링, 입력, UI
- `scenery.js` — 맵 배경(풀밭·흙길 6갈래·돌바닥 광장·숲·바위·덤불·꽃)과 성채(탑 4개·본성·대포·깃발·정문, 체력이 줄면 금→연기→불) 그리기. 배경은 512px 조각으로 한 번만 그려 캐시하고, 나무는 유닛과 y 순서로 함께 그린다. 규칙과 무관한 렌더링 전용 코드
- `figures.js` — 캐릭터 그리기 (동그란 머리 + 네모 몸통 + 칼·방패·활·지팡이·도끼, 적 6종·보스 6종). 규칙과 무관한 렌더링 전용 코드
- `tools/balance.mjs` — 밸런스 시뮬레이터 (아래)
- 테스트
  - `node tests/smoke.js` — 로직(골드·가격 규칙, 자동 라운드, 카드 규칙, 결정론, 봇 플레이)
  - `node tests/e2e.mjs` — 실제 Chrome을 실시간으로 조작 (게임 루프, 카드창, 드래그/휠, 종료/재시작). Chrome 경로는 `CHROME`, 대상 주소는 `URL0` 환경변수로 변경 가능
  - `tests/ui-test.html` — 입력 이벤트 빠른 점검 (`--allow-file-access-from-files --virtual-time-budget=8000 --dump-dom`)

## 밸런스 시뮬레이터
같은 `core.js`를 봇이 수천 판 돌려서 수치를 맞춘다 (멀티코어, 120판에 약 7초).
```
node tools/balance.mjs baseline 80                 # 정책별 클리어율·도달 라운드
node tools/balance.mjs hist 100                    # 종료 라운드 분포 (어디서 막히는지)
node tools/balance.mjs coredmg 80                  # 성채가 어떤 공격에 얼마나 맞는지
node tools/balance.mjs jobs 60                     # 전직별 기여도
node tools/balance.mjs cards 60 [smart] [save]     # 카드별 기여도 (그 카드를 보이면 항상 고를 때의 평균 라운드 변화)
node tools/balance.mjs sweep hpSlope 0.07,0.055 60  # 수치 스윕 (balance.*, popCap, startGold, leash, bias)
```
**밸런스 상태** (봇 120판, 현재 규칙: 적 체력·공격력 0.5배, 보스 무작위 순서, 시작 골드 210)
| 정책 | 클리어율 | 평균 라운드 | 8라운드 전 사망 |
|---|---|---|---|
| 숙련 카드 선택 | 약 28~34% | 27.7 | 0% |
| 무작위 카드 선택 | 약 20% | 26.5 | 0% |

목표는 숙련 약 30~35%, 무작위 10~20%. 초반(1~12라운드)은 일부러 쉽게 두었고(온보딩), 막히는 곳은 20~21·25~26라운드(보스)와 30라운드(마왕)다.

**이번 보정에서 찾은 것** (성채가 맞은 피해 출처 측정 `node tools/balance.mjs coredmg`): ① 성채 피해의 **47%가 보스 포격**(범위 피해가 아군 옆의 성채까지 맞힘) → 성채는 보스 포격에 40%만 맞게 하고, 포격 피해의 이중 증가를 정리 ② 마왕전의 결정 요소는 **포격 2발 동시 발사**(1발이면 클리어 57%, 2발이면 18%) → 마왕 포격 피해 120→100으로 35% 구간에 맞춤 ③ 후반 체력 증가율·보스 체력·소환 수·방어막은 클리어율에 거의 영향이 없었음 ④ 직업 중 기사만 약해(클리어 22% vs 평균 33%) 체력 보너스 +60%→+80% ⑤ 카드별 기여도는 대부분 오차(±1라운드) 안이라 현재 난이도에서는 카드보다 유닛 수·경제가 승패를 좌우한다.

**지금까지 찾아 고친 것**: ① 유닛이 성채에서 너무 멀리 추격해 각개격파됨 → 추격 한계 520→240 ② 효과 없는 이속 카드 제거, 약한 카드(방어·소환·사제) 상향, 강한 카드(관통 화살·대형 포탄) 소폭 하향 ③ 명령 모드 제거 후 새 배치 방식(`ai.bias`, `leash`) 조정.

**알려진 한계**: 특수 유닛(골렘·용사·포탑)에는 능력치 카드와 전직이 적용되지 않고 오라·사제 치유만 받는다. 카드 기여도가 대부분 오차 안이라 카드 간 차별화가 약하다.
